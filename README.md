# framegrid

Frame CSV/TSV grid tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/framegrid/

## Install / run

```bash
git clone https://github.com/theworker02/framegrid.git
cd framegrid
node src/cli.js
node --test
```
